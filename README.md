# Hogparts AI Assistant

AI product and fitment assistant for Hogparts UK Ltd.

## Safety principles
- Catalogue-grounded answers only.
- Never invent fitment, stock, specifications, prices or delivery information.
- Fitment is confirmed only when Hogparts catalogue data explicitly supports it.
- Hogparts UK Ltd is independent and has no relationship with Harley-Davidson.

## Environment
- OPENAI_API_KEY
- OPENAI_MODEL (optional)
- SHOPIFY_STORE_DOMAIN
- SHOPIFY_STOREFRONT_TOKEN

The development interface is deliberately separate from the live Shopify theme.
